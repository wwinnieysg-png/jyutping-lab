03 / ABOUT簡單，夠用，就好

畀文字一個
啱嘅讀法。

粵音修正所係一個針對廣東話 Text-to-Speech 嘅前端工具實驗。設計靈感來自日系實驗型網站嘅留白、柔色視覺同輕微動態，但查字與修正流程保持清晰易用。

網站毋須 Firebase 或登入。字庫透過 GitHub Actions 下載及整理，再由 GitHub Pages 靜態提供；自訂字詞可喺 custom-words.csv 直接編輯。講稿草稿與複製格式只保留於你目前嘅瀏覽器。
